# Muhammad Abiyyu Rahman

**System Architecture · Secure Development · IT Governance**

> I care more about how a system holds up over time than how impressive it looks on paper.

My work sits where system architecture, security, and governance meet. I build software that people can trust with real data and real consequences once it's live. I design role-based access control, audit trails, and segregation of duties in from the start instead of adding them later. A system that fails quietly is worse than one that fails loudly.

## What I've built

Production systems, designed and delivered end to end:

| System | What it does |
|---|---|
| **BYK MSA** · sales monitoring | Android + web app for field sales: location-based check-ins, watermarked photo evidence, offline drafts that sync later, Leaflet visit maps, and automatic PDF reports. It runs in 3 regions with 5 access levels. *Node.js, MySQL, PWA, Capacitor.* |
| **Ami Ali POS** · multi-outlet retail | Point of sale for a perfume retailer with 10 outlets: per-role permissions managed from one panel, real-time stock per outlet, and an automatic activity log for audit. |
| **SIMPEG** · HR data (PLN Nusantara Power) | A central HR system for several partner companies. Access is scoped at the data layer, so each company only sees its own staff, and Excel imports are validated before anything is saved. |
| **AJB** · fuel distribution ERP | Eleven operational modules from order to payment, almost 20 roles, segregation of duties ("the maker can't approve their own transaction"), and tiered approvals for large transactions. |
